🗺️ Welcome to Delve

Delve is a self-contained, offline-first Virtual Tabletop (VTT) for tabletop RPGs.

Single file. The entire app is one HTML file you can save, share, or host anywhere.
The Two Roles
👑
Dungeon Master
Builds maps, controls fog of war, moves tokens, manages initiative. Sees token list overlay on the play screen.
⚔️
Player
Sees only what the DM revealed. Moves their token, uses ruler/ping tools. Customize floating tools via ⚙️.
Getting Started
  • Create a map: Tap Map Maker, paint terrain tiles, place tokens.
  • Start a session: Go to Session, choose map, tap Open Session as DM.
  • Players join: Enter the 6-character room code and their name.
  • Reveal the map: In the play screen, open Controls, use Reveal tool.
⚒️ Map Editor
Brush Size (1–50)

Brush size now goes from 1 to 50 cells. Add the Brush Size floating button (🖌️) via the 🔧 menu to get a quick popup slider. You can also use + / − keyboard shortcuts or the toolbar ± buttons.

Brush Size Float Button

When the 🖌️ Brush Size button is in your floating tools, tapping it opens a popup with a slider and quick-set buttons (1, 3, 5, 10, 20, 50). Tap outside or tap the button again to close it.

Two-finger pan

Use two fingers to pan and pinch-zoom on touch devices. The fix ensures single-finger painting is never triggered while two fingers are (or were) active in the same gesture.

Sub-pixel painting

Enable SubPx mode to paint fine detail within cells using a sub-grid (2×2 – 8×8).

🎭 Tokens
Hidden Tokens

Check 🫥 Hidden from players in token properties. Hidden tokens are never revealed to players even when fog is removed. DM sees them dimly with a 🫥 badge.

⚔️ Play Screen
Two-finger Pan

Use two fingers on touch screens to pan and pinch-zoom. Lifting one finger after a two-finger gesture will NOT accidentally paint fog or place tiles.

Player Floating Tools
  • 📍 Ping: Place a ping visible to all.
  • 📏 Ruler: Drag to measure distance in feet.
  • ✋ Pan: Toggle map panning mode.
  • 👤 Find Me: Center view on your token.
  • 🔄 Reset Move: Reset your movement tracker.
