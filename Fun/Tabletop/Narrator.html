🔫 Mafia

Classic Mafia with Godfather, Cop, Doctor, and more. Works similarly to Classic Werewolf.

How to Play

Mafia uses the same core system as Classic Werewolf, just with different role names. Configure it using the Classic Werewolf setup — the roles map as follows:

  • Werewolf → Mafia
  • Seer → Cop / Detective
  • Doctor → Doctor
  • Minion → Informant
  • Hunter → Vigilante
  • Bodyguard → Bodyguard

Audio Files

Custom Audio

You can add custom audio files for each narrator line. Place MP3/WAV files in an /audio/ directory with filenames matching the role keys. The app will look for:

  • audio/everyone_close.mp3
  • audio/werewolf_wake.mp3
  • audio/werewolf_close.mp3
  • audio/seer_wake.mp3
  • ...etc for each line

If no audio file exists, the narrator text will display without audio (or use browser TTS if enabled below).
