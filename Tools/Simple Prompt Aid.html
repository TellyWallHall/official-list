📋 Prompt Structure Checklist

Structure

Use Clear Section Headers

Organize your prompt with explicit sections like "## ROLE", "## OBJECTIVE", "## CONSTRAINTS". This helps the AI parse instructions correctly.

## ROLE
You are a senior software architect...

## OBJECTIVE
Design a scalable microservices architecture...
Clarity

Be Specific, Not Vague

Replace ambiguous words with precise instructions. Quantify when possible.

❌ Bad:
"Make it better"
"Add some details"
"Be thorough"
✅ Good:
"Reduce latency by 50%"
"Include 3 examples"
"Cover all 5 phases"
Context

Provide Rich Context

The more relevant context you give, the better the output. Include:

  • • Domain: Industry, project type, tech stack
  • • Audience: Who will read/use this output?
  • • Constraints: Budget, timeline, team size
  • • History: Previous decisions, existing systems
Output

Specify Output Format Exactly

Tell the AI exactly how you want the response structured:

  • • Markdown: Headers, bullets, bold for emphasis
  • • JSON: Specify schema with required fields
  • • Table: Define columns explicitly
  • • Length: "Keep under 500 words" or "Be comprehensive"
Advanced

Chain-of-Thought Prompting

Ask the AI to reason step-by-step before giving a final answer. This dramatically improves quality for complex tasks.

"Think through this step-by-step:
1. First, analyze the requirements
2. Then, identify potential approaches
3. Evaluate trade-offs for each
4. Finally, recommend the best option with justification"
Advanced

Use Constraints as Guardrails

Good constraints prevent unwanted behavior:

  • • "NEVER suggest solutions requiring more than 3 developers"
  • • "ALWAYS include risk assessment for each recommendation"
  • • "DO NOT exceed budget of $50,000"
  • • "MUST be compatible with existing Python 3.9 codebase"
Clarity

Define Success Criteria

Tell the AI what a "good" response looks like:

"A successful plan will:
✓ Cover all 4 project phases
✓ Include timeline estimates
✓ Identify at least 3 risks per phase
✓ Assign clear ownership
✓ Be achievable within 6 months"
Context

Few-Shot Examples Work

Show 1-3 examples of input → output pairs. This is often more effective than lengthy instructions.

"Example 1:
Input: 'Build a login page'
Output: { task: 'Login Page', priority: 'High', estimate: '2 days', dependencies: ['Auth API'] }

Now process: 'Build a dashboard'"
Structure

Iterate & Refine

Great prompts aren't written in one pass. Test your prompt, observe the output, then refine. Use the AI Assistant to help identify what's missing or unclear.
